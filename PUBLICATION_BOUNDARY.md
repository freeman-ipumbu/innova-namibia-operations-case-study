# Public case-study boundary

This repository presents the identity and public experience created for Innova Investments CC. It is a portfolio record, separate from the private production website repository and its operational data.

## Included

- The design brief, service architecture and public visitor journeys
- A small, curated set of public-facing identity and website images
- High-level descriptions of the request desk, rentals, supply and client portal
- Clear labels for enhanced source imagery and representative concept imagery
- Links to the current website and the original Innova site

## Kept private

- Production application source, configuration, deployment files and database schema
- API credentials, authentication details, access policies and integration secrets
- Enquiries, customers, bookings, invoices, portal links and staff information
- Internal dashboard imagery and unpublished client or commercial material
- The full-resolution artwork and product image libraries

The case study describes the designed and implemented experience. It does not claim measured revenue, conversion, delivery or customer outcomes. Examples of possible projects are not represented as completed Innova jobs. Public visibility of the images and writing does not grant a licence to reuse them.
